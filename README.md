# Jaytika Gattani - Personal Resume Website

Built with HTML5 and CSS3 only (no JavaScript).

## Files
- index.html, about.html, experience.html, projects.html, contact.html
- css/style.css (the single stylesheet)
- images/profile.jpg

## Publish on GitHub Pages
1. Create a new public repository on github.com (e.g. `resume-website`).
2. Click "uploading an existing file" and drag in everything INSIDE this folder
   (index.html must be at the top level, not inside another folder). Commit.
3. Go to Settings > Pages > Source: "Deploy from a branch" > Branch: main, folder: / (root) > Save.
4. After 1-2 minutes your site is live at https://YOUR-USERNAME.github.io/resume-website/
